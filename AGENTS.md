# Jain Gaming Centre — Website Guidelines

This repository contains the official website and repair portal for **Jain Gaming Centre** (Indore, MP, India).

## Tech Stack

- **Framework**: Vite + React 19 + TypeScript
- **Routing**: TanStack Router (Client SPA)
- **Styling**: Tailwind CSS v4 + Lucide React
- **Deployment**: GitHub Pages (Static hosting via GitHub Actions)
