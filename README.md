# Jain Gaming Centre — Official Website

> Indore's Premier Console Store & Repair Lab since 2000.

PlayStation 5, Xbox Series X/S, and Nintendo Switch sales, Hall-Effect zero-drift upgrades, microscope micro-soldering, certified pre-owned consoles, and trade-ins.

## Features

- **Store Catalog**: Interactive console, controller, and accessory showcase with direct WhatsApp checkout.
- **Repair Cost Estimator**: Live instant pricing and turnaround time estimation for common console issues.
- **Trade-In Estimator**: Instant trade-in valuations for pre-owned consoles.
- **Store Hours & Live Indicator**: Real-time store open/closed status based on Indian Standard Time.
- **Mobile First & Responsive**: Optimized for fast loading and seamless browsing across all screen sizes.

## Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing**: [TanStack Router](https://tanstack.com/router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [GitHub Pages](https://pages.github.com/) via GitHub Actions

## Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## Deployment to GitHub Pages

This repository includes an automated GitHub Actions workflow (`.github/workflows/deploy.yml`) that builds and deploys to GitHub Pages upon every push to the `main` branch.
